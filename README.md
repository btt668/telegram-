# telegram供需信息发布机器人
telegram供需信息发布机器人，通过机器人自助发布信息到tg群和频道里面
修改env 和 config文件后

服务器安装python3+以上
终端
项目目录执行以下命令
pip3 install -r requirements.txt
然后
python3 bot.py

重启机器人命令：
systemctl restart mybot
